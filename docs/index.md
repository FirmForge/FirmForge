# FirmForge 使用手册

FirmForge 是一个 Windows 桌面应用：用 OpenWrt / ImmortalWrt 官方 ImageBuilder 生成固件——选设备、挑软件包、写首次启动配置，点一下开始构建，产物直接在资源管理器里定位。

- 仓库：<https://github.com/FirmForge/FirmForge>
- 交流：<https://t.me/MomoFlora>
